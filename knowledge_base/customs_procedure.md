# Customs Procedure

## Customs Issues

Shipments with customs-related exceptions should be reviewed for the current customs status and available documentation.

If customs clearance is pending, operations should verify whether additional documentation or information is required.

Customs-related delays should not automatically be attributed to the carrier unless the shipment record contains evidence supporting that conclusion.

## Documentation

Operations should verify required customs documentation before escalating a customs exception.

Customer communication may be required when customs documentation or clearance issues materially affect shipment delivery.
